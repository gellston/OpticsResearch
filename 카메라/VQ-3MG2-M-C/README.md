## 시스템 조합 참고

- **FOV** = 센서 사이즈(mm) ÷ 렌즈 배율 — 카메라 단독 값이 아니라 렌즈와 조합할 때 결정됩니다.
- **시스템 공간 분해능** = 픽셀 사이즈 ÷ 배율 → 배율 1x에서 약 3.45 µm/px, 배율 10x에서 약 0.345 µm/px (픽셀 사이즈 원문: 3.45 × 3.45)
- **렌즈 선택 조건**: 이미지 서클 ≥ 센서 대각선, 렌즈 마운트 = 카메라 마운트, 렌즈 광학 분해능 ≥ 시스템 요구 분해능.
- 이 카메라의 광학 포맷: **1/1.8"**
