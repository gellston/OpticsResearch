## 시스템 조합 참고

- **FOV** = 센서 사이즈(mm) ÷ 렌즈 배율 — 카메라 단독 값이 아니라 렌즈와 조합할 때 결정됩니다.
- **센서 사이즈(계산)** = 픽셀사이즈 × 해상도 → **7.4444 x 5.6166 mm** (FOV 계산 기준)
- **시스템 공간 분해능** = 픽셀 사이즈 ÷ 배율 → 배율 1x에서 약 1.85 µm/px, 배율 10x에서 약 0.185 µm/px (픽셀 사이즈 원문: 1.85 x 1.85)
- **렌즈 선택 조건**: 이미지 서클 ≥ 센서 대각선, 렌즈 마운트 = 카메라 마운트, 렌즈 광학 분해능 ≥ 시스템 요구 분해능.
- 이 카메라의 센서 포맷: **1/1.7"**
